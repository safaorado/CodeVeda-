# Machine Learning Internship Portfolio - Codveda Technology

Welcome to my machine learning portfolio! This repository contains the end-to-end data science pipelines and classification models I developed during my Python Development Internship with Codveda Technologies. 

The projects demonstrate a complete progression from foundational data preprocessing to deploying advanced ensemble methods and deep learning architectures.

#Tech Stack & Tools
* Language: Python
* Libraries: Pandas, NumPy, Scikit-Learn, TensorFlow/Keras, Matplotlib, Seaborn
* Environment: Jupyter Notebook / Google Colab
* Version Control: Git & GitHub

  Tasks & Objectives Completed

#Level 1: Foundations
- Data Preprocessing: Cleaned and formatted the Telecom Customer Churn dataset, applying label encoding and one-hot encoding to prepare categorical data for predictive modeling.
 - imple Linear Regression: Built a baseline model to predict continuous variables using the Boston Housing dataset, evaluating performance via Mean Squared Error (MSE) and R-squared.
- K-Nearest Neighbors (KNN): Engineered a distance-based classifier for the Iris dataset. Evaluated the optimal number of neighbors (K) and visualized the results via a confusion matrix.

#Level 2: Intermediate Classification & Clustering
- Logistic Regression:** Developed a binary classifier to predict customer churn, interpreting feature impact using Odds Ratios and evaluating discriminative ability with an ROC Curve.
- Decision Trees: Trained and visualized a pruned decision tree to categorize Iris species, identifying the exact threshold measurements the algorithm used for classification.
- K-Means Clustering: Applied unsupervised learning to uncover hidden behavioral segments within the customer base. Utilized the Elbow Method to determine the optimal number of clusters.

#Level 3: Advanced Modeling
- Random Forest Classifier: Deployed a robust ensemble model on the churn dataset. Evaluated performance using 5-fold cross-validation and extracted feature importances (identifying "Total Day Charge" as the leading churn factor).
- Support Vector Machines (SVM): Trained SVM models to classify customer churn, comparing Linear and Radial Basis Function (RBF) kernels to visualize complex 2D decision boundaries.
